What's new in 0.3.0
- Foreign keys: add, change or remove them in the Structure tab (MySQL), and click the arrow on a foreign key cell to open the referenced row.
- Structure editor: change a column's position by typing a number, pick a type from a list or type your own, and a clearer active row.
- Undo and redo for pending row edits with Ctrl+Z and Ctrl+Y.
- Top bar: Save, Discard and Review changes sit in the middle, plus a light and dark theme toggle and an Update badge.
- Updates: the update dialog opens on start when a new version is found.
- Installer: choose to install for just you or for all users, so updates work from Program Files too.
- About: shows your OS, architecture and install date, and copies them one per line for bug reports.
- Smaller things: connection initials from the first two words, a picked database opens in an empty connection, the query log timestamp no longer wraps.
