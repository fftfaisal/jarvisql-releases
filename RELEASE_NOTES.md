What's new in 0.6.0
- Export and import connections: export one connection, a group or all of them to a .jarvisql file. Passwords are optional and encrypted with a passphrase you choose. On import, a connection with the same name is replaced, or tick Import as copy to keep both.
- Connection URLs: copy a MySQL or MariaDB connection as a URL, or import one with Import from URL. TablePlus-style mysql+ssh:// URLs work too.
- Open database links: clicking a mysql://, mariadb://, mysql+ssh:// or mariadb+ssh:// link opens JarvisQL. After you confirm, it connects without saving the connection, and it's gone when you close it. SSH links that use a key ask for the key file.
- Smaller things: JarvisQL now runs as a single window, so a link opens in the window you already have. The installers carry the new description, publisher and website, and Linux packages show JarvisQL properly in the app center.
